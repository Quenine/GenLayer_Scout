# GenLayer Scout v0.3.0 release checklist

This is a developer-facing manual smoke-test checklist for the v0.3.0 Evidence Manifest v1 release. The steps require a real browser and a working RPC verification. Results are **not** recorded or claimed here; they are only confirmed by actually performing each step.

## Prerequisites

- A verified experiment whose saved verification result and snapshot are intact (see the Verify route).
- The app reporting `v0.3.0`.
- A downloaded `.manifest.json` file generated by this build.

## A. Generate a manifest from a verified experiment

- [ ] Open the Evidence page.
- [ ] Enter implementation references (repository URL, commit, deployment URL) in the Portable manifest section.
- [ ] Confirm the Generate manifest action is enabled once prerequisites are met.
- [ ] Generate the manifest and confirm the preview appears with a SHA-256 digest.

## B. Same digest in preview and download

- [ ] Click Download JSON manifest and save the file.
- [ ] Compare the digest shown in the preview with the `integrity.digest` value in the downloaded JSON.
- [ ] Confirm they are identical.

## C. Inspect the downloaded file — Valid

- [ ] Open the Inspect manifest section.
- [ ] Choose the downloaded `.manifest.json` file.
- [ ] Confirm the status is **Valid**.
- [ ] Confirm the recorded and recomputed digests match.

## D. Edit one payload field without changing the digest

- [ ] Make a copy of the manifest file.
- [ ] Edit a single payload value (for example, the contribution title) in the copy, leaving `integrity.digest` unchanged.

## E. Inspect the edited copy — Modified

- [ ] Inspect the edited copy.
- [ ] Confirm the status is **Modified**.
- [ ] Confirm the copy is not reported as **Valid**.

## F. Inspect malformed JSON — Invalid

- [ ] Create a file that is not valid JSON (for example, truncated or unquoted content).
- [ ] Inspect it.
- [ ] Confirm the status is **Invalid** (or a clear read/parse error is shown).

## G. Inspect a recognized manifest with unsupported version — Unsupported

- [ ] Create a copy of a valid manifest and change `payload.version` to a value this release does not support (for example, `2`), keeping the format string intact.
- [ ] Inspect it.
- [ ] Confirm the status is **Unsupported**.

## H. Inspecting does not alter the workspace

- [ ] Before inspecting, note the current Evidence pack title and experiment selection.
- [ ] Inspect any of the files above.
- [ ] Afterward, confirm the Evidence pack, experiment selection, and workspace are unchanged.
- [ ] Refresh the browser and confirm no inspected manifest content was persisted to the workspace.
